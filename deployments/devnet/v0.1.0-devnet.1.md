## Integration freeze

Suzi integrations must pin the tag, source commit, Program ID, and executable
hash recorded above. Do not upgrade this Program ID during integration work.
If the on-chain program changes, create a new source commit, rebuild and verify
the artifact, deploy the upgrade, and publish a new release tag such as
`v0.1.0-devnet.2` with its own deployment record.
